# Put FarePool online

GitHub access is not connected on this computer, so only you can create the online repository.

1. Sign in to [GitHub](https://github.com) as **prabal2404**.
2. Click the **+** button in the top-right corner, then select **New repository**.
3. Name it `farepool-jaipur`.
4. Select **Public** so free hosting can use it.
5. Do not add a README, `.gitignore`, or licence on GitHub—the project already has these files locally.
6. Click **Create repository**.
7. Copy the new repository link from the page and send it here.

The repository will be new and separate. It will not change any of your existing GitHub projects.
